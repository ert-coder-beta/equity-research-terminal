ERT Alpha 1.4.3 VALUATION CLICK FIX

Root cause:
Alpha 1.4.2 defined the recovery valuation page in a new IIFE, then overrode window.render and called layout14()/bind14().
Those functions are private to the earlier Alpha 1.4 IIFE, so clicking Valuation could throw a ReferenceError before the page rendered.

Fix:
- Keep navigation/render/layout entirely inside the working Alpha 1.4 renderer.
- Export only valuation142.
- Alpha 1.4 page map uses window.valuation142 when available.
- No cross-scope calls to layout14 or bind14.
