# ERT GOOG Alpha 0.7

Integrated test build based on the latest feedback.

Key changes:
- Mobile navigation drawer added.
- Mobile Evidence & Analysis Inspector becomes a bottom sheet.
- Overview includes ERT star rating, moat, quality, growth, financial health, capital allocation, valuation and risk.
- ROIC now has a plain-English explanation and ROIC-vs-WACC context.
- Reverse DCF keeps the market-implied FCF growth number and adds base/history/multiple context.
- Historical valuation table adds plain-English definitions, range markers and interpretation.
- Analysis uses green/amber/red hierarchy, adds consensus comparison and upcoming catalysts.
- Consensus is explicitly labelled DEMO / provider-integration placeholder and always shows source/as-of/analyst count.
- WACC is decomposed into risk-free, beta, ERP, cost of debt, tax and market-value capital weights.
- Terminal growth has benchmark references and sanity checks.
- FCF basis displays actual 5Y average FCF margin when selected.
- Market page shows SMA20/50/200 cards, actual date labels, moving-average curves, RSI panel and plain-English interpretation.
- Result section shows data dates / calculation date.
- Report includes star ratings and plain-language narrative.

Important:
This build is for workflow/UI testing. Financial figures are fixed test data. Consensus and upcoming-event data are demo placeholders, not live market data.
