# Data Model v1

## Company
ticker, CIK, legal name, exchange, reporting currency, fiscal year end, sector, industry.

## Filing
accession number, form, filing date, report date, primary document.

## Financial Fact
company, filing, statement, line item, XBRL concept, period start, period end, fiscal year, fiscal period, unit, raw value, normalised value, source URL, confidence status.

## Valuation
model version, base date, assumptions, formula outputs, scenario, author, last modified.

## Research Note
company, category, body, created at, modified at, status.
